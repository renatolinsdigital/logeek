# Decisions

One file per decision that a newcomer would otherwise question: a framework,
a database, a provider, a departure from a dev-boilerplate guide. Name it
`NNNN-short-title.md`, numbered in order, and never edit an accepted one:
a later decision supersedes it and links back.

```markdown
# NNNN. Title

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by NNNN

## Context
What forced a choice, and the constraints.

## Decision
What was chosen.

## Consequences
What gets easier, what gets harder, what to watch.
```
